# Лянга-спорт — Варис Шамсуев

Адаптивный лендинг о Варисе Шамсуеве и развитии лянга-спорта.

На сайте: история проекта, основные приёмы игры, идея двоеборья «Лянга + дартс», фотографии, четыре видео и контакты.

## Структура

- `dist/index.html` — содержание страницы.
- `dist/style.css` — оформление и адаптивная версия.
- `dist/app.js` — галерея, просмотр фото и видео.
- `dist/assets/` — фотографии и видео.
- `vercel.json` — настройки публикации на Vercel.

## Локальный просмотр

```sh
python3 -m http.server 4173 --directory dist
```

Откройте http://localhost:4173.

## Публикация

Статический сайт без сборки и серверных зависимостей. Vercel публикует каталог `dist`.

Материалы предоставлены заказчиком. События 2027 года и двоеборье с дартсом описаны как планы. Телефоны взяты из предоставленного буклета.
